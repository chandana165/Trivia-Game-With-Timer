# 🧠 Trivia Game with Timer

An interactive trivia game that delivers a **timed question-and-answer experience** across multiple categories. Players race the clock, earn points for correct answers, choose a difficulty level, and see how they rank on the leaderboard.

## ✨ Features

- ⏱️ **Countdown timer** for every question
- 📚 **Multiple categories** to choose from
- 🎚️ **Difficulty levels** that change the challenge
- 🏅 **Scoring system** that rewards correct answers
- 🏆 **Leaderboard** to compare scores
- 📱 **Responsive design** that works on desktop and mobile

## 🚀 Run Locally

No installation is needed.

```bash
git clone https://github.com/chandana165/Trivia-Game-With-Timer.git
cd Trivia-Game-With-Timer
```

Then open `index.html` in your browser.
